# 🧠 C Projects Portfolio

A growing portfolio of C programming projects focused on practical applications, command-line tools, and system-level problem solving. This repository includes modular builds, file operations, and logic-driven utilities — with new projects added regularly.

## 🚀 Purpose

This repository serves as a central hub for my C development work. Each project explores core programming concepts such as memory management, file I/O, data structures, and CLI interaction — all with a focus on clean, functional code and real-world use cases.

## 🧰 Technologies Used

- C (C99 or later)
- GCC / Clang
- Standard libraries: `stdio.h`, `stdlib.h`, `string.h`, etc.
- Modular design and function-based architecture
- Makefiles (where applicable)

## 📁 Project Structure

Each folder represents a standalone project and includes:
- `README.md` – Project overview and usage
- Source files (`.c`, `.h`)
- Sample input/output files (if applicable)
- Build instructions or Makefile
